# Rehab Monitor Sim — สเปก (จากรอบ grilling 2026-11-11)

## เป้าหมาย
- Simulator **ฝึกเท่านั้น** ไม่ใช้ตัดสินใจกับผู้ป่วยจริง
- รอบแรก = ต้นแบบเล่นได้ 3 เคส ส่งลิงก์ให้เพื่อน PT ลองเล่น + เก็บ feedback
- ผู้เล่น: นักศึกษา PT / PT จบใหม่ · cardiac rehab phase II (outpatient)

## การเล่น
- ก่อนเคส: chart (Dx, กี่สัปดาห์หลังผ่า, ยา รวม beta-blocker, HR/BP พัก, เป้าหมาย)
- เวลาย่อ: 1 วินาทีจริง = 6 วินาทีใน session (30 นาที ≈ 5 นาที) มีนาฬิกา session
- เกิดเหตุการณ์ → sim หยุด (คลื่นยังวิ่ง) → เลือก ไปต่อ / เพิ่ม / ลด / หยุด + ติ๊กเหตุผลจากรายการ
- เพิ่ม/ลด = ระบบปรับลู่ ~1 MET (สมการ ACSM) แสดง METs
- แต่ละเคส 2–3 จุดตัดสินใจ จุดแรกมักปกติ (ฝึกไม่ over-react)
- หลังตอบ: เฉลยทันที + strip คลื่นไฮไลต์จุดผิดปกติ + อ้างอิง แล้ว "ครูพี่เลี้ยง" ปรับตามคำตอบที่ดีที่สุดแล้วเล่นต่อ (เส้นเรื่องเดียว)
- คะแนน: ดีที่สุด (2) / ยอมรับได้ (1) / ไม่ปลอดภัย-ไม่เหมาะสม (0) + เหตุผลถูกได้สูงสุด 1
- จบเคส: หน้าสรุป · เล่นครบ 3 เคส → ปุ่ม Google Form

## จอและข้อมูล
- Telemetry lead II ลีดเดียว คลื่นสังเคราะห์ (Gaussian ต่อ wave) มี noise + motion artifact
- HR (จากมอนิเตอร์) · SpO₂/PR · NIBP (กดวัด ใช้เวลา 3 วิ) · RPE (กดถาม) · อาการ (คนไข้พูด)
- เสียงบี๊บตาม QRS (pitch ตาม SpO₂) + alarm HR >150 / <40 · ปุ่มปิดเสียง
- 3D (three.js) คนประกอบจาก primitive เดิน/วิ่งตามความเร็วลู่ แสดงอาการ: เหงื่อ/ซีด, กุมอก, จับราว

## 3 เคส
1. หลัง CABG + metoprolol: RPE ต่ำกว่าเป้า → **เพิ่ม** · motion artifact คล้าย VT แต่คนไข้ปกติ → **ไปต่อ**
2. หลัง PCI: ST ↓ 0.5 mm → **ไปต่อ** · horizontal ST ↓ ~2.5 mm + แน่นอก + เหงื่อ → **หยุด**
3. หลัง CABG: PVC เดี่ยว unifocal → **ไปต่อ** · AF ใหม่ RVR 140+ ใจสั่น SBP ตก → **หยุด** (ลด = ยอมรับได้)

- ติดป้าย "ร่าง ยังไม่ได้รีวิวโดยผู้เชี่ยวชาญ" · เพื่อน PT รีวิวรอบแรก · cardiologist ก่อนเปิดวงกว้าง
- ผู้รีวิวต้องปักหมุด edition/หน้า ของแต่ละอ้างอิง
